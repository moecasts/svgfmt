# Changelog

All notable changes to this project will be documented in this file.

## [0.0.0] - 2024-11-26

### Added

- **Initial release** of `@svgfmt/iconify`
- `importDirectory()` - Import SVG files from directory with automatic `@svgfmt/core` formatting
- `exportToDirectory()` - Export IconSet as individual SVG files
- `exportJSONPackage()` - Export IconSet as npm-ready Iconify JSON package
- Full TypeScript support with comprehensive type definitions
- Complete test coverage with 10 test cases
- Detailed documentation and examples
- Integration with `@iconify/tools` ecosystem

### Features

- Automatic SVG processing using `@svgfmt/core`
- Customizable icon naming via `keyword` callback
- Default dimensions configuration
- Icon set metadata support
- Custom file injection for npm packages
- Compatible with all `@iconify/tools` workflows
